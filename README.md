# SENTARA-Metode-Akuisisi-Sensor-Toleran-Adaptif-Berbasis-Rust
Metode SENTARA (Sensor Tolerant Adaptive Rust-based Acquisition) merupakan sebuah metode akuisisi data multi-sensor yang dirancang khusus untuk sistem pemantauan suhu dan kelembaban secara real-time dengan tingkat keselamatan kritis tinggi.
